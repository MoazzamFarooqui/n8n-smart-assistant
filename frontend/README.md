#  n8n Mini – Learn n8n Easily

An interactive AI-powered educational platform that helps beginners learn **n8n** through simple explanations, practical examples, workflow templates, and an intelligent AI Mentor—all in one place.

**Learn n8n without switching between documentation, YouTube videos, and multiple websites.**

#  Overview

**n8n Mini** is a modern, responsive learning platform designed for students, beginners, freelancers, developers, and automation enthusiasts who want to master **n8n** in a simple and interactive way.

Instead of reading lengthy documentation, users can explore:

* n8n Nodes
* Workflow Examples
* Integrations
* JSON Files
* Credentials
* APIs
* Automation Concepts
* AI Agents
* AI Calling Agents
* Practical Guides
* Interactive Quizzes
* AI Mentor

The platform combines educational content with AI-powered assistance, making learning faster, easier, and more engaging.

---

#  Problem Statement

Learning n8n can be challenging because:

* Official documentation is overwhelming.
* There are hundreds of nodes to understand.
* Workflow logic is difficult for beginners.
* Integrations require multiple credentials.
* APIs and JSON can be confusing.
* Learning resources are scattered across multiple websites.
* Beginners often have no one to guide them while learning.

---

#  Solution

n8n Mini brings everything together into one modern educational platform.

Users can:

* Learn popular n8n nodes
* Understand integrations step-by-step
* Explore workflow examples
* Learn JSON basics
* Search nodes instantly
* Read beginner-friendly guides
* Ask the AI Mentor questions anytime
* Learn automation concepts without technical complexity

#  Installation

Clone the repository

```bash
git clone https://github.com/your-username/n8n-mini.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
